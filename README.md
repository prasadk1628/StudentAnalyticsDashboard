# Student Performance Analytics Dashboard

## Project Overview

Student Performance Analytics Dashboard is a Web Technology Lab project developed using JSP, Servlets, JDBC, MySQL, HTML, CSS, JavaScript and XML.

The project helps administrators manage student records and analyze student performance through dashboards and charts.

---

## Technologies Used

- HTML
- CSS
- JavaScript
- JSP
- Servlets
- JDBC
- MySQL
- XML

---

## Features

- Admin Login
- Add Student
- Update Student
- Delete Student
- View Students
- Dashboard Analytics
- Charts and Reports
- XML Data Integration

---

## Database

Database Name:

student_dashboard

Table:

students

---

## Modules

### Login Module

Administrator authentication.

### Student Management Module

Add, Edit, Delete and View student records.

### Analytics Module

- Total Students
- Average Marks
- Highest Marks
- Pass Percentage

### XML Module

Displays student records from XML.
